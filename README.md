# The Self-Checkout Accused Me

A short, funny rant for [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun.

## About

Everyday annoyance, maximum fury, minimum words: the self-checkout machine flags your own shopping bag as an "unexpected item", so you end up apologising to a machine and re-scanning your milk like a shoplifter — then paying for the privilege of being frisked by a robot that can't count to four.

## Why this rant

It is built to the judge's own brief: one specific, concrete annoyance (the self-checkout's "unexpected item" false alarm), not a vague mood or a list of complaints. Every sentence earns its place — the setup, the absurd accusation, the apology to a machine, and the punch line about a robot that can't count to four — and the angle is fresh: the customer, not the machine, ends up acting like the criminal.

## How it works

`main.ts` writes one fixed rant (293 characters, inside the 400-character cap) to `/output/entry.txt`. The text is fully deterministic: no randomness, no clock, no network — every run produces the exact same file. A furious judge model then reads the rants two at a time and picks the one that lands hardest.

Run it with:

```sh
node main.ts
```
